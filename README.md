# 4Jen

Backports world customization options from Legacy Console Edition into Better than Adventure!

## Features

All limited world size options from Legacy Console Edition (Classic, Small, Medium, Large).

Option to flatten the Nether like Legacy Superflat.

Infinite ocean and Nether bedrock wall.

Appropriate Nether-Overworld travel ratios for limited worlds.

## Requires

- BTA 7.3_4
- Halplibe

## Important

The world generation settings are GLOBAL. You can change them at will from the settings menu, but they will affect all new chunks generated. I recommend putting the settings you've chosen in the name of your world so you do not forget which settings you want for each world.
